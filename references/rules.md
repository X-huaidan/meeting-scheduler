# 排会规则

本文件定义孟总会务助手在排会时遵循的所有规则。所有规则按类别组织，方便查阅、增删、修改。

> **修改约定**：每条规则用 `- **规则名**：描述` 格式。新增规则直接在对应类别末尾追加即可，删除规则删除对应行。

---

## A. 表格操作规则

### A.1 底色填充

- **A.1.1 孟总会议底色**：含"邓"的会议 → 参会领导只写"邓"，整行 **C:I** 列填 **浅橙2 `#FFDCC4`**（RGBA 255,220,196,100）
- **A.1.2 其他领导会议底色**：无邓、含"姜" → 参会领导只写"姜"，整行 C:I 填 **浅绿2 `#C3EAD5`**（RGBA 195,234,213,100）
- **A.1.3 多领导处理**：若参会领导同时含邓和姜 → 仅写邓（按 A.1.1 优先级更高）
- **A.1.4 填色范围**：仅 C 列到 I 列，A、B 两列不填色
- **A.1.5 无特殊领导**：若参会领导中无任何被本表标记的领导（邓/姜/孟/...），按原样写、不填底色

### A.2 文字对齐

- **A.2.1 左对齐列**：E（议程）、H（参会人员）
- **A.2.2 居中对齐列**：C（时间）、D（会议名称）、F（地点）、G（参会领导）、I（组织人）
- **A.2.3 默认对齐**：B 列（日期）按表格现状保留（通常为居中或左对齐）

### A.3 文字换行

- **A.3.1 自动换行列**：E（议程）、H（参会人员）
- **A.3.2 其他列**：保持单行（不强制换行，避免意外撑高行）
- **A.3.3 行高联动**：开启换行的列，行高需配合调整，否则多行文字被截断

### A.4 字体（待定）

- **A.4.1** 字体、字号、粗细目前未做统一规定，保留表格默认。如需规范请在此追加。

### A.5 单元格合并（待定）

- **A.5.1** 当前不合并任何单元格。如需合并（如合并当天的"时间"单元格）请在此追加。

### A.6 边框（待定）

- **A.6.1** 当前不调整边框。如需加边框请在此追加。

### A.7 行高与列宽

- **A.7.1 会议行默认行高**：60pt
- **A.7.2 午休分隔行**：9~20pt 窄行（**这是分隔行的标志**，不是隐藏行）
- **A.7.3 列宽**：保留表格现状，不主动调整
- **A.7.4 行高还原上限**：`setRowHeightsForced(r,1,60)` 实际最高只到 45pt；如需 60pt，必须手动到 UI 调

### A.8 隐藏与显示行

- **A.8.1 隐藏行快捷键**：`Ctrl+Alt+9`（**不是 Ctrl+Shift+9**）
- **A.8.2 取消隐藏快捷键**：`Alt+Shift+9`
- **A.8.3 `Ctrl+Z` 不能恢复被隐藏的行**
- **A.8.4 隐藏前提**：必须**整行选中**（点击行号列 x≈28），快捷键才生效
- **A.8.5 取消隐藏范围**：选中被隐藏行的**上下邻行**（整行）后按 `Alt+Shift+9`
- **A.8.6 备用方式**：右键行号 → "隐藏行" 菜单（不受输入法干扰）
- **A.8.7 禁止模拟隐藏**：不能用 `setRowHeightsForced(r,1,1)` 模拟隐藏，用户无法恢复，会永久污染表格
- **A.8.8 隐藏状态判定**：唯一可靠办法是**截图看行号是否跳号**；沙箱 `getRowHeight()` 返回"行高设置值"，不反映隐藏状态

## B. 会议安排规则

### B.1 时间格式

- **B.1.1 时间字符串格式**：`HH:MM-HH:MM`，如 `11:20-12:00`
- **B.1.2 写入位置**：C 列
- **B.1.3 跨天会议**：本表只排当日会议，跨天会议拆成两天分别排
- **B.1.4 冲突处理**：时间冲突由用户协调，agent 只标记不裁决

### B.2 参会领导处理

- **B.2.1 孟总默认在场**：若参会领导中**没有"孟"**，自动把"孟"加在**房**后面（例：原"房" → "房孟"）
- **B.2.2 已有孟**：若参会领导中已有"孟"，保持原样不加
- **B.2.3 多领导去重**：参会领导列表中重复出现某人，只保留第一次
- **B.2.4 写入位置**：G 列

### B.3 参会人员处理

- **B.3.1 多人员格式**：用顿号 `、` 或空格分隔均可（按用户原话）
- **B.3.2 自动换行**：H 列开自动换行
- **B.3.3 左对齐**：H 列为左对齐
- **B.3.4 写入位置**：H 列

### B.4 议程处理

- **B.4.1 议程格式**：每条议程用数字编号，如 `1.开场 2.讨论 3.总结`
- **B.4.2 多条议程**：用空格分隔（不用换行，靠自动换行排版）
- **B.4.3 自动换行**：E 列开自动换行
- **B.4.4 左对齐**：E 列为左对齐
- **B.4.5 写入位置**：E 列

### B.5 会议名称

- **B.5.1 写入位置**：D 列
- **B.5.2 居中对齐**

### B.6 地点

- **B.6.1 写入位置**：F 列
- **B.6.2 居中对齐**

### B.7 组织人

- **B.7.1 写入位置**：I 列
- **B.7.2 居中对齐**

### B.8 每天布局

- **B.8.1 每天结构**：
  ```
  [标记行 B=周X]            ← 必保留
  [上午若干会议行]          ← 有则保留
  [午休分隔行]              ← 行高 9~20，保留
  [下午若干会议行]          ← 有则保留
  [空白行（无会议时段）]    ← 全部隐藏
  ```
- **B.8.2 可见行规则**：只保留"标记行 + 会议行 + 午休分隔行"，**所有空白行隐藏**
- **B.8.3 上午只有一场**：该场应**紧贴午休分隔行上方可见**，上午其余空白行隐藏
- **B.8.4 下午只有一场**：该场应**紧贴午休分隔行下方可见**，下午其余空白行隐藏
- **B.8.5 全天无会议**：保留标记行 + 午休分隔行，全天空白行隐藏

## C. 输入处理规则

### C.1 文字输入

- **C.1.1 必填字段**：日期、时间、会议名称。其他字段（议程/地点/参会人/组织人）缺则留空
- **C.1.2 解析顺序**：日期 → 时间 → 会议名 → 议程 → 地点 → 参会领导 → 参会人员 → 组织人
- **C.1.3 时间冲突**：发现同一时间段有多个会议时，**先暂停写入并提示用户**

### C.2 截图识别

- **C.2.1 来源**：支持企业微信截图、其他聊天工具截图、邮件截图
- **C.2.2 识别字段**：会议标题、时间、地点、参会领导、参会人员、议程
- **C.2.3 模糊字段处理**：识别不出的字段标注"待确认"，不擅自补全
- **C.2.4 截图识别后必须给预览**，让用户确认后再写入

### C.3 不完整输入

- **C.3.1 时间缺失**：必须问用户补时间
- **C.3.2 会议名称缺失**：必须问用户补会议名
- **C.3.3 领导缺失**：按 B.2.1 自动补"孟"在"房"后
- **C.3.4 其他字段缺失**：留空，不主动询问（避免打断用户）

## D. 工作流规则

### D.1 写入流程

- **D.1.1 读取结构**：每次开工前用 sandbox 读取 B:I 列 + 行高
- **D.1.2 识别与预览**：把识别结果展示给用户（含目标行号、底色、领导栏写法）
- **D.1.3 用户确认**：必须用户说"确认"才执行写入
- **D.1.4 写入**：先写值 → 再写底色 → 再设对齐 → 再设换行
- **D.1.5 回读校验**：写入后回读确认

### D.2 错误处理

- **D.2.1 MCP sandbox 偶发 `code -12 missing data not found` 或 tcp timeout**：直接重试，通常第二次成功
- **D.2.2 CDP 端口不通**：让用户重新以 `chrome.exe --remote-debugging-port=9222` 启动 Chrome
- **D.2.3 sandbox 日志截断**：分批读取（每批 20 行左右）
- **D.2.4 误改行高**：用 `setRowHeightsForced` 恢复，最多到 45pt；超过 45pt 需手动 UI 调

### D.3 破坏性操作

- **D.3.1 隐藏行前**：截图留档
- **D.3.2 写入前**：预览确认
- **D.3.3 写入后**：回读校验
- **D.3.4 不模拟隐藏**：禁止用 `setRowHeightsForced(r,1,1)`

## E. 自定义规则（用户专属）

以下规则是本表（孟总行程表）专属，不适用于其他表格：

- **E.1 孟总加"房"后**：参会领导无"孟"时自动补在"房"后面（见 B.2.1）
- **E.2 邓、姜优先级**：含邓时只写邓，含姜（无邓）时只写姜（见 A.1.1、A.1.2）
- **E.3 浅橙2 透明度 100**：底色透明度固定 100（不是 100%，是 RGBA 第 4 个值为 100）
