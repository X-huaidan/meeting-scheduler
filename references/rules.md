# 排会规则

本文件定义孟总会务助手在排会时遵循的所有规则。所有规则按类别组织，方便查阅、增删、修改。

> **修改约定**：每条规则用 `- **规则名**：描述` 格式。新增规则直接在对应类别末尾追加即可，删除规则删除对应行。

## A. 表格操作规则

### A.1 底色填充

- **A.1.1 孟总会议底色**：含"邓"的会议 → 参会领导只写"邓"（**其他人移到参会人员列，见 B.2.2**），整行 **C:I** 列填 **浅橙2 `#FFDCC4`**（RGBA 255,220,196,100）
- **A.1.2 其他领导会议底色**：无邓、含"姜" → 参会领导只写"姜"（**其他人移到参会人员列，见 B.2.2**），整行 C:I 填 **浅绿2 `#C3EAD5`**（RGBA 195,234,213,100）
- **A.1.3 多领导处理**：若参会领导同时含邓和姜 → 仅写邓（按 A.1.1 优先级更高）
- **A.1.4 填色范围**：仅 C 列到 I 列，A、B 两列不填色
- **A.1.5 无特殊领导**：若参会领导中无任何被本表标记的领导（邓/姜/孟/...），按原样写、不填底色

### A.2 文字对齐

- **A.2.1 左对齐列**：E（议程）、H（参会人员）、**I（组织人）**
- **A.2.2 居中对齐列**：B（日期）、C（时间）、D（会议名称）、F（地点）、G（参会领导）
- **A.2.3 垂直对齐**：全部**居中**（v_align=center）
- **A.2.4 水平对齐以"改动前的原始渲染"为准**：2026-09-14 用像素测量逐列核对过——
  B/C/D/F/G 的文字左右留白相等（居中），E/H/I 的 Lpad≈4px（左对齐）。
  ⚠️ 本条曾误写成"I 列居中"。I 列被视口裁切，肉眼看容易看错，
  **判定必须用"同一行同一单元格在改动前后 text 像素区间是否相同"来验**（实测 I 列两侧都是 `[1863-1908]`）

### A.3 文字换行

- **A.3.1 自动换行列**：E（议程）、H（参会人员）
- **A.3.2 其他列**：保持单行（不强制换行，避免意外撑高行）
- **A.3.3 行高联动**：开启换行的列，行高需配合调整，否则多行文字被截断

### A.4 字体（待定）

- **A.4.1** 字体、字号、粗细目前未做统一规定，保留表格默认。如需规范请在此追加。

### A.5 单元格合并（待定）

- **A.5.1** 当前不合并任何单元格。如需合并（如合并当天的"时间"单元格）请在此追加。

### A.6 边框（待定）

- **A.6.1** 当前不调整边框。如需加边框请在此追加。

### A.7 行高与列宽

- **A.7.1 会议行默认行高**：60pt
- **A.7.2 午休分隔行**：9~20pt 窄行（**这是分隔行的标志**，不是隐藏行）
  - **🔑 识别方法（2026-09-14 实测权威，务必照此判定）**：
    1. 沙箱 `SpreadsheetApp.getActiveSheet().getRowHeight(r)`（**行号 1-based**）读行高。
       实测：普通会议行 = 60，**午休分隔行 = 9~10**（很矮），天间间隔行 = 19~20。
    2. 再用 `sheet.get_merged_cells` 取 B 列日期合并块（如 `B3:B12`）= 该天的行区域；
       区域内的那条窄行就是当天的午休分隔行。
  - ⚠️ **绝不能用"标记行 + N"推算**：2026-09-14 实测每天偏移是 **3/4/6/5/5**（周一~周五），
    并不规律；上一轮就是因为按"+3"硬推，把 R17/R29/R44/R55（普通空行）
    误当成午休行，导致真正的午休行 R18/R32/R46/R57 一直被藏在隐藏区里
- **A.7.3 列宽**：保留表格现状，不主动调整
- **A.7.4 行高还原上限**：`setRowHeightsForced(r,1,60)` 实际最高只到 45pt；如需 60pt，必须手动到 UI 调

### A.8 隐藏与显示行

- **A.8.1 隐藏行快捷键**：`Ctrl+Alt+9`（**不是 Ctrl+Shift+9**）
- **A.8.2 取消隐藏快捷键**：`Alt+Shift+9`
- **A.8.3 `Ctrl+Z` 不能恢复被隐藏的行**
- **A.8.4 隐藏前提**：必须**整行选中**快捷键才生效。首选 `Ctrl+Home` 定位 → `ArrowDown` 到目标行 → **`Shift+Space` 选中整行**（键盘链路）；鼠标点击行号列 x≈28 也行但慢
- **A.8.5 取消隐藏范围**：选中范围必须**跨越被隐藏的段落**（含上下邻行），再按 `Alt+Shift+9`；扩展时**多扫 30 行余量**保证跨越
- **A.8.6 备用方式**：右键行号 → "隐藏行" / "取消隐藏行" 菜单。**仅作兜底**——菜单路径比键盘慢约 50 倍
- **A.8.7 禁止模拟隐藏**：不能用 `setRowHeightsForced(r,1,1)` 模拟隐藏，用户无法恢复，会永久污染表格
- **A.8.8 隐藏状态判定**：**枚举可见行取缺口**——`Ctrl+Home` 后反复按 `ArrowDown`（自动跳过隐藏行），收集到的行号序列中缺失的就是隐藏行。比截图看跳号准且可编程校验
  - ⚠️ **键盘失灵会误报（2026-09-14 踩坑）**：页面处于异常状态（选区/编辑态残留）时
    `ArrowDown` 会完全不动，`visible_rows` 只返回极短列表，把整表误判成"全隐藏"。
    **一旦看到"几乎全隐藏"这种极端结果，先 `Page.reload` 再复核**，不要急着"补救"
    ——上一轮因此白跑了一轮 fix 脚本，其实隐藏集一直是对的
  - 沙箱 `getRowHeight()` **不反映隐藏状态**（隐藏行仍返回原值），但它**能识别窄行**（见 A.7.2）

### A.10 视图滚动与截图（2026-09-14）

- **A.10.1 滚动视图的正确方式**：用 `_rowsx.goto_row(c, r)` 移动活动单元格——表格会自动把目标行滚入视野。
  `ArrowDown`/`ArrowUp` 也可以用。**但注意名称框不更新，不要靠 `active()` 判断选区终点**
- **A.10.2 `PageDown` 无效**：在网格里按 `PageDown` 不会翻页（活动单元格纹丝不动）
- **A.10.3 不要拉高视口**：`Emulation.setDeviceMetricsOverride(height=3800)` 截出来是
  3800px 高，但 **canvas 只渲染原视口那部分**，下面全是空白 → 白费功夫，还会让渲染状态变脏
- **A.10.4 检查午休行的标准动作**：`scripts/_check.py 6 18 32 46 57`（午休行号作参数），
  输出隐藏集并逐条验证午休行是否可见
- **A.8.9 午休分隔行永不隐藏**：午休分隔行（行高 9~20pt 的窄行）**任何情况下都不能隐藏**，必须始终可见作为上午/下午的示意（详见 B.8.7）。批量隐藏时要**主动排除**这些行

### A.9 键盘链路（2026-09-14 打通，隐藏/展开的首选路径）

- **A.9.1 必须用 `rawKeyDown`**：`Input.dispatchKeyEvent` 的 `type` 填 `keyDown` 时页面**完全无响应**（曾因此误判"canvas 收不到键盘事件"）；填 **`rawKeyDown`** 才生效。修饰键掩码：Shift=8、Ctrl=2、Alt=1
- **A.9.2 性能差异（实测）**：鼠标点击 ~1.7 秒/次、**鼠标滚轮 40 秒→超时**（canvas 无 DOM 滚动容器）、键盘 ~30 毫秒。**能走键盘就别走鼠标**
- **A.9.3 快捷键链路**：`Ctrl+Home`（回 A2）→ `ArrowDown`（跳过隐藏行）→ `Shift+Space`（选整行）→ `Shift+ArrowDown`（扩展）→ `Ctrl+Alt+9`（隐藏）/ `Alt+Shift+9`（取消隐藏）
- **A.9.4 精确跳行**：不能按固定次数 ArrowDown（隐藏行会导致 overshoot）。先枚举可见行，算目标行之前有几个可见行，就按几次
- **A.9.5 批量算子**：`scripts/_j_do.py`，token 语法 `U13-68`（展开）/ `H18-24`（隐藏），每个 op 后自动重探可见行自校验。**推荐两阶段**：先 `U` 展开拿干净基线 → 再按清单 `H` 逐段隐藏
- **A.9.6 入口与常驻**：`scripts/_boot.py`（钉死 CDP_PORT、绕代理、自动拉起 Chrome）＋ `scripts/_hold.py`（后台常驻，端口死自动重启）。操作脚本统一 `from _boot import connect`，**不要自己启动 Chrome**
- **A.9.7 浏览器常驻**：单独打开的 Chrome **任务结束也不关闭**，用户要随时查看进度
- **A.9.8 ⚠️ 隐藏行不能当键盘锚点（2026-09-14 深夜踩坑）**：`goto_row` 是靠 `ArrowDown` 逐行走的，
  而 `ArrowDown` **会自动跳过隐藏行**，所以**目标行只要处于隐藏状态就永远跳不到**
  （报错形如 `goto_row(58) stuck at 65`）。
  **取消隐藏的正确姿势**：锚定**隐藏段上方最近的可见行**（如午休行），
  `Shift+Space` 选整行 → 长距离 `Shift+↓` **跨越整段隐藏行** → `Alt+Shift+9`；
  展开后按目标可见集把多出来的行**重新隐藏**。
  示例（展开周五 R58）：`_j_do.py "U57-58" "H59-64"` —— `U57-58` 会从 57 一路扫到 88，
  把 58-64 全展开，再 `H59-64` 收回去，最终只留 R58
- **A.9.9 写完样式/内容后画布可能还是旧画面**：`set_cell_style` / 值写入之后**立即截图**，
  可能仍是**改动前**的渲染（本次新增的绿行截出来是空白、像素扫描全白，差点误判"底色没写进去"）。
  **判定以回读为准**（沙箱 `getRange()`）；**要截图必须先 `Page.reload` 再截**（见 A.13.5）

### A.11 ⚠️ `set_cell_style` 是全量覆盖（2026-09-14 事故，最高优先级）

- **A.11.1 语义**：`sheet.set_cell_style` **未传的属性一律被重置为该属性的默认值**：
  `bg_color`→白、`font_color`→黑、`bold`→false、`horizontal_align`→left、`font_size`→10。
  **它不是"只改我传的字段"，而是"整片区域的样式以本次参数为准"。**
- **A.11.2 事故经过**：2026-09-14 为了开自动换行，只传了 `wrap_text=true`、范围 A1:I83，
  结果**表头的蓝底 / 白字 / 加粗 / 居中，以及会议行的浅绿底色，全部被抹掉**
  （用户第二天发现："表头的字体、底色为啥没了，然后格式的对齐也不对"）
- **A.11.3 铁律**：**每次调用都必须把该区域所有要保留的属性显式传全**：
  `bg_color` + `font_color` + `bold` + `font_size` + `horizontal_align` + `vertical_align` + `wrap_text`
- **A.11.4 顺序**：对齐类调用会抹掉底色 → **底色恢复必须放在最后**，
  且恢复底色的那几次调用**也要把 `bg_color` 带上**（否则会被自己抹掉）
- **A.11.5 交互相乘**：底色行里各列对齐不同，所以绿行要按列拆开写：
  先 `C:I` 整段（h=居中 + bg）→ 再把 `E` 单列、`H:I` 改成左（**各带 bg**）

### A.13 CDP 补充踩坑（2026-09-14）

- **A.13.1 点击前必须 `Page.bringToFront`**：否则 `Input.dispatchMouseEvent` 发出去不生效
  （标签页不在前台时点击被丢弃）。顺序：`bringToFront` → `mouseMoved` → `mousePressed` → `mouseReleased`，
  且要带 `pointerType:"mouse"`、`buttons`（moved 时为 0）
- **A.13.2 重载后名称框是空的**：`Page.reload` 之后没有任何活动单元格，
  `document.querySelector('.bar-label').value` 返回 `''`
  → 此时 `_rowsx.visible_rows()` 只会返回 `[None]`，看起来像"整表全隐藏"（同 A.8.8 的误报）。
  **正确做法：重载后先点一次网格拿到活动单元格，再走键盘链路；不要据此"补救"隐藏集**
- **A.13.3 重载不会断 CDP**：`eval` 在 reload 后依然可用（`1+1` 正常返回），不用重连 websocket
- **A.13.4 截图裁剪要留余量**：测某列文字位置时，窗口右边界若正好切在文字上，
  会漏掉真正的文字、把边框像素误当成文字。**取色/取文字区间时窗口要比目标宽 100px 以上**
- **A.13.5 写入后必须 `Page.reload` 才能看到新画面（2026-09-14 深夜）**：
  `set_cell_style` / 写入值之后，**画布不一定重绘**——本次新增的绿行，
  写入后立刻截图是**空白白底**，像素扫描里连一点绿都没有；
  `Page.reload` + `settle=8` + `sleep(3)` 之后再截，绿色才出现（`y476-542 #C3EAD5`）。
  → **顺序固定为：写入 → 回读校验（沙箱取值）→ `Page.reload` → 截图/像素校验**。
  **绝不要凭"写完立刻截的图"判断样式是否生效**
- **A.13.6 行号口径（务必背下来）**：
  - 沙箱 `SpreadsheetApp.getActiveSheet().getRange(r, c)` 用的是 **1-based = 表格 UI 行号**
    （与 rules.md 里写的 `R52`／`_j_do.py` 的 `"H54-54"` 同一口径）
  - `sheet.get_cell_data` / `set_cell_style` / `clear_range_cells` 的 `start_row`/`end_row`
    用 **0-based**，即 **`MCP 行号 = UI 行号 - 1`**（实测 `start_row=52` 返回 UI 第 53 行）
  - ⚠️ **多行 CSV 输出偶发错位**（本次遇到一次：`start_row=51..58` 的输出里少了中间一行）。
    **判定"第几行是什么"一律用"单行小窗口 `get_cell_data`"或"沙箱 `getRange`"复核**，
    不要靠数 CSV 的空行（同 A.7.2、B.9 的告诫）

## B. 会议安排规则

### B.1 时间格式

- **B.1.1 时间字符串格式**：`HH:MM-HH:MM`，如 `11:20-12:00`
- **B.1.2 写入位置**：C 列
- **B.1.3 跨天会议**：本表只排当日会议，跨天会议拆成两天分别排
- **B.1.4 冲突处理**：时间冲突由用户协调，agent 只标记不裁决
- **B.1.5 时间缺失（只写"上午/下午"）**：**不要问用户、不要自己猜**，直接按 **B.12** 的默认起点排

### B.2 参会领导处理（G 列）

- **B.2.1 领导栏只写关键领导**：参会领导栏**只保留关键领导**，其余人一律移到参会人员列
  - 含**邓** → G 列**只写"邓"**
  - 无邓、含**姜** → G 列**只写"姜"**
  - 无邓无姜 → G 列写"**房总、孟总**"（**孟总排在房总后面**）

## D. 工作流规则

### D.1 写入流程

- **D.1.1 读取结构**：每次开工前用 sandbox 读取 B:I 列 + 行高
- **D.1.2 识别与预览**：把识别结果展示给用户（含目标行号、底色、领导栏写法）
- **D.1.3 用户确认**：必须用户说"确认"才执行写入
- **D.1.4 写入**：先写值 → 再写底色 → 再设对齐 → 再设换行
- **D.1.5 回读校验**：写入后回读确认

### D.2 错误处理

- **D.2.1 MCP sandbox 偶发 `code -12 missing data not found` 或 tcp timeout**：直接重试，通常第二次成功
- **D.2.2 CDP 端口不通**：让用户重新以 `chrome.exe --remote-debugging-port=9222` 启动 Chrome
- **D.2.3 sandbox 日志截断**：分批读取（每批 20 行左右）
- **D.2.4 误改行高**：用 `setRowHeightsForced` 恢复，最多到 45pt；超过 45pt 需手动 UI 调

### D.3 破坏性操作

- **D.3.1 隐藏行前**：截图留档
- **D.3.2 写入前**：预览确认
- **D.3.3 写入后**：回读校验
- **D.3.4 不模拟隐藏**：禁止用 `setRowHeightsForced(r,1,1)`

## E. 自定义规则（用户专属）

以下规则是本表（孟总行程表）专属，不适用于其他表格：

- **E.1 孟总加"房"后**：参会领导无"孟"时自动补在"房"后面（见 B.2.3）
- **E.2 邓、姜优先级**：含邓时领导栏只写邓，无邓含姜时只写姜（见 A.1.1、A.1.2、B.2.1）
- **E.3 浅橙2 透明度 100**：底色透明度固定 100（不是 100%，是 RGBA 第 4 个值为 100）
- **E.4 关键领导独占领导栏**（2026-09-14）：G 列只放关键领导（邓 / 姜 / 房总+孟总），
  数据源里同栏的其他领导**一并移到 H 列**，按原顺序混排（见 B.2.1、B.2.2）
- **E.5 参会人员只写姓氏**（2026-09-14）：H 列一律姓氏写法，不带"总"字（见 B.3.1）
- **E.6 孟在房后**（2026-09-14）：房、孟同栏时孟排在房后面（见 B.2.6）
- **E.7 午休行永不隐藏**（2026-09-14）：午休分隔行任何情况都保留可见（见 A.8.9、B.8.7）
