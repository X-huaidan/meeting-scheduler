### v1.4.0 (2026-09-14)

**跨设备可用 + 排会规则定稿 + 周二整日收版。**
本版的起因是"**家里电脑从头安装这个技能**"——装完 CDP 通道直接不可用，
顺带暴露出一批只在单一机器上才不会命中的问题。

**① 跨设备路径解耦（不改的话家里电脑一跑就崩）**
- 全仓库 **9 处硬编码了公司机器用户名 `changan`** → 全部改成运行时动态解析：
  - `scripts/_boot.py` / `_launch_chrome.py`：Chrome 调试 profile → `os.path.expandvars(r"%USERPROFILE%\...")`
  - `scripts/publish_to_baidu.py`：`SKILL_DIR` → `Path(__file__).resolve().parent.parent`；`PYTHON` → `Path.home() / ...`
  - 6 处文档路径同步：`SKILL.md` §数据源、`rules.md` C.2.5、`cdp_notes.md` §1、`publishing.md` §4/§8、`sheet_ui_cheatsheet.md`
- 全仓库 grep `changan` **0 残留**；三个改动脚本 `py_compile` 通过

**② 新规则 B.12：时间缺失时的默认排法**
- 数据源只写「上午 / 下午」、**没有 `HH:MM-HH:MM`** → **从 13:40 开始按 60min 顺排**，不再停下来问
- 用户原话："后续只写了上午和下午，没写具体时间的，就按照**下午一点四十**开始按顺序往后排"
- ⚠️ **B.12.7：以后遇到"没写时间"直接排，不要追问** —— 此前为「S07 亮相&上市汇报」只写了"下午"卡住过一整轮

**③ 新规则 B.2.8：不补源数据没写的领导**
- 源数据只写「孟总」时，G 列**只写「孟总」**，**不要**按 B.2.1 补成「房总、孟总」
- 用户原话："没写房总的就不用写房总"
- 本条**优先于 B.2.1 的"补房"方向**；B.2.3（只有"房"时补"孟"）不受影响，仍然有效

**④ 周二整日收版 + 收版规则修正**
- 周二可见集：`R14 标记 / R17 会 / R18 午休 / R19 会 / R20 会 / R25 间隔`；隐藏 `H15-16 H21-24`，午休行保留 ✅
- ⚠️ **B.8.9：每天收版前必须重新实测可见集** —— 旧基线 `H15-17 H20-24` 是"周二只有一场会"时的值，
  照抄会把会议行一起藏掉（周二变成 R17+R19+R20 三场会后，隐藏段完全不同）
- 🚫 **周一永久不收版**（用户明确："周一不用收版"），R4/R6/R10-12 保持展开

**⑤ 通道能力实测结论（已写进 `cdp_notes.md` §1 / `rules.md`）**
- **沙箱（通道 A）确认没有隐藏行接口**：Sheet 对象无 `hideRows/showRows`，
  只有 `getRowHeight/setRowHeight(s)/getColumnWidth/setColumnWidth`；
  且 **行高不能当隐藏判据**（已隐藏的 R29 / R33-39 仍返回真实高度）→ **收版只能走 CDP**

  ⚠️ **页面标题仍是"孟总会议行程表"，不能用标题判断登录态**，必须先截图确认

**⑥ 发布策略收紧（用户立规矩，见 `publishing.md` §5 铁律）**
- **禁止每次改动就发版**：只有用户明确说"发版"才允许改 `version` + CHANGELOG + commit + push

### v1.3.0 (2026-09-14)

本版是**单日大幅迭代**：打通键盘链路、连修三处规则误判、经历一次格式被抹事故并逐像素还原，
最后做了一次**文档分层瘦身**。规则细节见 `references/rules.md` 的修改记录。

**① 键盘链路打通（性能 ×50）**
- 根因：此前误判"canvas 收不到键盘事件"，实际是 `Input.dispatchKeyEvent` 用了 `keyDown`；
  改用 **`rawKeyDown`** 后完全可用。**更正旧结论**：`Alt+Shift+9` 一直有效，
  右键菜单降为兜底（慢约 50 倍）
- 实测：键盘 `~30ms/次`、鼠标 `~1.7s/次`、**鼠标滚轮 40s 超时**（canvas 无滚动容器）
- 链路：`Ctrl+Home` → `↓`（自动跳过隐藏行）→ `Shift+Space` → `Shift+↓` → `Ctrl+Alt+9` / `Alt+Shift+9`
- 新脚本：`_kb.py`（键盘原语）、`_rowsx.py`（行导航）、`_j_do.py`（**批量算子**）、
  `_check.py`（版面体检）、`_shot.py`（截图）、`_pix.py`（像素校验）
- **隐藏行判定升级**：枚举可见行取缺口（可编程校验），取代"截图看跳号"

**② Chrome 常驻**
- 新增 `_hold.py`：后台守护，端口死自动重启（满足用户"浏览器持续展示不要关闭"的要求）
- `_boot.py` 统一入口：钉死 `CDP_PORT` + 绕代理 + 自动拉起 Chrome + 截图重试；
  `snap()` 支持 `SNAP_DIR`，不再把截图写进技能目录

**③ 版面规则补充**
- 新增 **B.10 排会范围**：「**周末不排会**」（用户明确："周末的会议数据不需要排"），
  周末现有内容保留原状不清空
- 新增 B.8.6 天间保留 1 个空白行做间隔 / B.8.7+A.8.9 **午休分隔行任何情况都不隐藏** /
  B.8.8 单天冻结（"某天先不动"）
- 新增 **B.8.9 每天目标可见集**（整日收版标准）

  其余人按原顺序移到 H 栏；H 栏**只写姓氏**。新增 E.4~E.7

**④ 🔴 格式被抹事故 & 逐像素还原（本版最重要的教训）**
- 起因：为"全表打开自动换行"只传了 `wrap_text=true`，而 **`set_cell_style` 是全量覆盖** ——
  未传的属性全部重置为默认值 → **表头蓝底/白字/加粗/居中 + 会议行底色全被抹掉**
  （用户次日反馈："表头的字体、底色为啥没了，然后格式的对齐也不对"）
- 新增 **A.11 全量覆盖铁律**：每次调用必须显式传全
  `bg_color/font_color/bold/font_size/h_align/v_align/wrap_text`；**底色恢复必须放最后**，
  且恢复底色时也要带 `bg`；底色行要按 `C:I`→`E`→`H:I` 拆 3 次写
- 新增 **A.12 格式基线**（可逐像素复现）：表头 `#2972F4` + 白字 + **粗体 + 11pt**；
  正文 B/C/D/F/G 居中、E/H/I 左对齐、垂直全居中；绿行 `#C3EAD5`
- **更正 A.2/B.7**：I 列（组织人）原表是**左对齐**，此前误记为居中
- 新增 **A.13 CDP 补充踩坑**：点击前必须 `Page.bringToFront`；`Page.reload` 后名称框为空
